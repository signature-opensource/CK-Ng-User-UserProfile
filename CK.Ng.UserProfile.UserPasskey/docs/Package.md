Adds the passkey section to the "Sign-in methods" tab of the CK.Ng.UserProfile `/profile` page: the user
lists, renames, deletes (a recent login is required) and adds its passkeys.

See the [README](https://github.com/signature-opensource/CK-Ng-User-UserProfile/blob/stable/CK.Ng.UserProfile.UserPasskey/README.md).
